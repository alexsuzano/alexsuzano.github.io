MillSight supplementary site
============================

This folder is complete and ready to upload as the root of a GitHub Pages site.

Files to upload
---------------
Upload the entire contents of this folder, keeping index.html, assets, downloads,
and .nojekyll together with the same names and structure.

Basic GitHub Pages setup
------------------------
1. Create a repository for the site.
2. Upload every item in this folder to the repository root.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, select "Deploy from a branch."
5. Choose the branch containing these files and the "/ (root)" folder, then save.
6. Open the Pages address after GitHub reports that deployment is complete.

Visitor password: suzano

Important security note
-----------------------
GitHub Pages is static hosting and is normally public. The included password screen
is a client-side presentation gate, not true access control. Someone with the direct
address of an asset or download may still be able to retrieve it.

Because this package contains internal mill material, do not publish it in a public
repository or public Pages site without company approval. For real password or
identity protection, use approved company hosting or an access-control service in
front of the site.
